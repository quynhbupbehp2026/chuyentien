Đưa trang này lên GitHub Pages

Thực hiện các bước đơn giản sau để có link dùng vĩnh viễn:

  1. Đăng nhập GitHub.com.
  2. Tạo một Repository mới và để trạng thái Public.
  3. Tạo file mới đặt tên chính xác là index.html.
  4. Dán toàn bộ mã nguồn này vào và nhấn Commit changes.
  5. Vào Settings → Pages, chọn branch main rồi chọn Save.
